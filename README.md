# Animation Catalogue

A client-ready, dependency-free animation catalogue with Enter, Hover, Group, Stagger, Preview buttons and image reveal demos.

## Features

- Enter animation demos
- Hover animation demos
- Preview buttons for every demo
- Stable hover wrappers to prevent blinking
- Group and stagger examples
- Image reveal demos
- Local inline SVG image previews
- Keyboard focus support
- Reduced-motion accessibility support
- Responsive layout
- No external libraries or build process

## Main File

Open `index.html` in a browser or enable GitHub Pages for the repository.

## GitHub Pages

1. Create a repository named `animation-catalogue`.
2. Upload `index.html`.
3. Open repository Settings.
4. Go to Pages.
5. Select the `main` branch and `/root` folder.
6. Save the settings.
